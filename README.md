## 🌟 Overview & Authentic Journalism Sources

Unlike generic food listings, **Namma Bengaluru Bhojan** is carefully curated from reputable publications and food critics:

- **Condé Nast Traveller India Top 50**: Progressive gastronomy, farm-to-table tasting menus, and cocktail lounges.

## 🍱 8 Curated Categories (44+ Spots)

1. **🍲 North Indian**: Regal Awadhi, Northwest Frontier, tandoor grills, and Delhi highway dhabas (*Kandahar, Dum Pukht, Punjab Grill, Copper Chimney, Dhaba Estd 1986, Tandoor, Ozaa*).
2. **🥥 South Indian**: Centennial benne dosa institutions, Mangalorean coastal seafood, and banana leaf feasts (*Vidyarthi Bhavan 1943, CTR Malleshwaram, MTR 1924, Karavalli Vivanta, Bengaluru Oota Company, Brahmin’s Coffee Bar, Rameshwaram Cafe, Nagarjuna*).
3. **🥗 Gujarati & Rajasthani**: Royal unlimited thalis and traditional farsan (*Khandani Rajdhani, Pankaj Delicacies, NH8, Kesariya, Rajdhani Thali Whitefield, Bhagatram Sweets 1948*).
4. **🍛 Biryani & Military Messes**: Maratha donne biryani, spicy Andhra biryani, and Tamil samba rice messes (*Shivaji Military Hotel 1924, Meghana Foods, Mani’s Dum Biryani, Rahhams Frazer Town, Ranganna Military Hotel, Ambur Star 1890*).
5. **☕ Cafés & Bakeries**: World-class French patisseries, specialty third-wave coffee roasteries, and English breakfasts (*Lavonne Academy & Café, Araku Coffee, Glen’s Bakehouse, The Hole in the Wall Café, DYU Art Cafe, Third Wave, Maverick & Farmer*).
6. **🍸 Nightlife & Microbreweries**: Craft beer pioneers, open-air mega-breweries, and molecular cocktail bars (*Toit Brewpub, Byg Brewski, Windmills Craftworks, Arbor Brewing Company, Bar Spirit Forward, Skyye Lounge UB City, Geist Brewing Factory, High Ultra Lounge*).
7. **🌍 International & Pan-Asian**: European fine dining, ethical farm-to-table degustation, handmade Tokyo ramen, and Burmese tea rooms (*Lupa, Farmlore, Naru Noodle Bar, Burma Burma, The Only Place 1965, Chianti*).
8. **🍢 Street Food Hubs**: Famous evening street food lanes and Bengaluru chaat innovations (*VV Puram Food Street, Sri Sairam’s Chats Malleshwaram*).

## 🛠️ Built-in Interactive Tools

- 🔍 **Live Search Bar**: Search instantaneously by dish, restaurant name, or area.
- 📍 **Neighborhood Selector**: Filter by Indiranagar, Koramangala, Malleshwaram, Basavanagudi, Jayanagar, MG Road, Whitefield, etc.
- 🕒 **Live Open/Closed Status Calculator**: Evaluates current local time and displays live status (`🟢 Open Now • Closes 1:00 AM` or `🔴 Closed • Opens 11:30 AM`).
- 🚗 **Parking Guidance on every card**: Details valet parking, dedicated lots, mall parking, or street advice.
- 🎲 **Food Roulette / Surprise Me**: Randomizer for undecided diners.
- 📋 **WhatsApp Sharing Tool**: 1-click formatted copy to clipboard.
- 🗺️ **One-Click Google Maps**: Instant GPS navigation link.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/PriyankaBisariya/BangloreFood.git

# Navigate to the folder
cd BangloreFood

# Run with Python HTTP server
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in any modern browser!
